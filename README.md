A 4 KB Python chess engine: 0x88 board, alpha-beta with transposition table, killer and history ordering, quiescence, null-move pruning and late-move reductions, driven over the tiny-chess-01 env.

## Run it

```sh
MAKEFUN_ENV_URL=<env> python3 -P -s main.py
```
